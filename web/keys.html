How your keys are protected

  • Password needed to add, change or remove a key (5 wrong tries → locked for 5 minutes).
  • Encrypted on disk (AES-256-GCM); the files are git-ignored, so they never go to GitHub.
  • Write-only: after saving, only the last 4 characters are ever shown.
  • Hidden everywhere: anything that looks like a key is removed from messages, the AI chat and logs.
  • Only this app can talk to the key page (other websites are blocked).
  • Before you push to GitHub, run python -m scripts.check_secrets (or enable the pre-commit hook).
