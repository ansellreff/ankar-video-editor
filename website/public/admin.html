Set up your authenticator

The admin page needs a 6-digit code from an authenticator app (Google Authenticator, Microsoft Authenticator, 1Password…) every time. (Only the admin page needs this — normal accounts never do.)

  1. On your phone, install a free authenticator app: Google Authenticator or Microsoft Authenticator (App Store / Play Store).
  2. Type your password below and press Show the setup code.
  3. In the app, tap + → Scan a QR code and point the camera at the code that appears here.
  4. The app now shows “AnKar” with a 6-digit code that changes every 30 seconds. Type the current code below and press Confirm.

Keep the app on your phone — you'll need a fresh code each time you open this page.
