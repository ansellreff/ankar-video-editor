Get started

About 15 minutes the first time (mostly downloading). Nothing is installed on Windows — no admin rights, no registry, no PATH changes.

  1. Download

    Sign in and download the zip (about 22 MB). A free account only needs a username.

  2. Unzip it somewhere short

    Right-click the zip ▸ Extract All… and choose a folder such as Documents\AnKar Video Editor or C:\AnKar.

    Keep the folder path under 90 characters (Windows limits file paths), and avoid OneDrive-synced folders for big video projects.

  3. Run Setup once

    Double-click Setup AnKar Video Editor.bat. It downloads, into that folder only, and checks every file against its SHA-256 checksum:

    • the official portable Python 3.12 from python.org → runtime\
    • the exact Python packages the editor needs → runtime\Lib\site-packages
    • the Whisper subtitle model (539 MB) from Hugging Face → models\

    Then it runs a self-test and says Ready!

    If Windows SmartScreen asks about the .bat file, choose More info ▸ Run anyway — it's a plain text script you can open in Notepad to read.

  4. Start editing

    Double-click Start AnKar Video Editor.bat. Your browser opens http://localhost:8765 with a 1-minute Demo project. Keep the black window open while you edit; close it to stop.

  5. Optional: add your AI keys

    Menu bar ▸ API Keys: create your password (stored on your PC as a one-way hash), then add a key. The editor works without any key.

Updating

When a new version is out, the editor shows a red dot on Help and this site shows it on your account page.

  1. Download the new zip from your account page.
  2. Drag the zip onto Update AnKar Video Editor.bat in your AnKar folder (or just double-click it — it finds the newest zip in Downloads).
  3. It replaces the program files and runs Setup. Your projects, voices, keys and settings are kept.

What you need

  • Windows 10 (version 1803 or newer) or Windows 11, 64-bit
  • 8 GB RAM (16 GB recommended for long 4K projects)
  • A graphics chip with OpenGL 3.3 — almost every PC from the last 10 years
  • Microsoft Edge or Google Chrome
  • About 3 GB free disk space, plus room for your footage and exports
  • Internet for Setup, the AI features and the daily update check

Optional: offline AI voice

Install local AI voice (optional).bat adds the Chatterbox voice engine (about 4 GB, runs on the CPU) so narration works without ElevenLabs.

Uninstall

Delete the AnKar folder. Nothing is left anywhere else on your PC. (Copy your projects folder first if you want to keep your edits.)

Troubleshooting

"This folder's location is too long for Windows"

Move the whole folder somewhere shorter, e.g. C:\AnKar, and run Setup again. It continues where it stopped.

A download failed or "checksum mismatch"

Check your internet connection and run Setup again. A file that doesn't match its checksum is never used.

"localhost refused to connect"

The black AnKar window must stay open. Start it again with Start AnKar Video Editor.bat.

The self-test says graphics / OpenGL 3.3 is missing

Update your graphics driver (Windows Update ▸ Advanced options ▸ Optional updates, or your PC maker's website).

Windows Smart App Control blocked something

AnKar only uses signed, official files (python.org Python, PyPI packages). If one is still blocked, tell us on GitHub — please don't turn Smart App Control off.
